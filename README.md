# Distance Calculator Program

## Description
A simple Python program that converts kilometers to miles using a high-precision conversion constant factor.

## How to Run the Program
1. Ensure you have Python 3 installed.
2. Run the file using your terminal:
   ```bash
   python distance_calculator.py
   ```

## Input Needed
* **Distance in Kilometers**: A numeric value (e.g., 5).
* **Navigation choice**: A text response (yes or no).

## Sample Output
```text
=== Distance Calculator Program ===
Enter distance in kilometers: 5
Distance in miles: 3.106855
Do you want to convert another distance? (yes/no): no
Program ended. Goodbye!
```
